# Punkte je Wohnungskategorie statt einer Punktzahl je Haushalt

Ein Haushalt hat keine pauschale Punktzahl, sondern eine Gesamtpunktzahl je Wohnungskategorie: gespeichert wird nur die Grundpunktzahl (alles, was allein vom Haushalt abhängt), die Wohnraumausnutzung wird beim Erstellen der Rangliste je Zimmerzahl aufgeschlagen. Die Vergabegrundsätze (§3 Abs. 2) bewerten, ob ein Haushalt eine Wohnung ausfüllt; das hängt an der Zimmerzahl, eine einzige Zahl je Haushalt könnte es nicht abbilden.

## Consequences

Derselbe Haushalt hat in verschiedenen Ranglisten verschiedene Punkte und Ränge. Die Grundpunktzahl allein sagt wenig aus und wird deshalb nur in der Rangliste neben der Wohnraumausnutzung gezeigt.
