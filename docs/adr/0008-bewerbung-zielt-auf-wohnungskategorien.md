# Bewerbungen zielen auf Wohnungskategorien, nicht auf Wohnungen

Eine Bewerbung nennt einen oder mehrere Wünsche als strukturierte Wohnungskategorien (Zimmerzahl, Förderungsart, bei Bedarf Wohnungsart; jedes Feld darf „egal“ sein), nie eine konkrete Wohnung und nie Freitext. So steht ein Haushalt in jeder passenden Rangliste, und die Auswahl entsteht aus den tatsächlich vorhandenen Wohnungen, sodass ein Wunsch nicht von den Stammdaten abweichen kann. Die konkrete Wohnung entsteht erst bei der Erfüllung.

## Consequences

Wunschangaben der außerhalb gepflegten Bewerbungsliste werden beim Import geparst; was sich nicht ableiten lässt, wird als „nicht erkannt“ ausgewiesen statt stillschweigend verworfen.
